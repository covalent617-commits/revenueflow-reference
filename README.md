# RevenueFlow Reference

A navigable, responsive visual reference for the RevenueFlow CRM experience.

## Preview
https://covalent617-commits.github.io/revenueflow-reference/

## Scope
The prototype includes 14 workspaces: Dashboard, Opportunities, Customers, Quotes, Tasks, Attention, Forecast, Analytics, Leak Radar, Activity, Records, Team, Notifications, and Settings.

All figures and records are illustrative. This is a front-end reference only; actions are demonstrations and are not connected to the RevenueFlow backend.

## Design principles
- Dark navy workspace with amber emphasis and restrained status colours.
- Distinguish actual won revenue, weighted forecast, and unweighted open pipeline.
- Treat risk signals as evidence-based attention cues, not probability estimates.
- Keep quote acceptance separate from won revenue.
- Avoid fabricated historical comparisons when no baseline exists.
